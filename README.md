# Dhanushka Dilshan — portfolio

A one-page portfolio built with [Astro](https://astro.build), styled with the "dark room" direction
from the taste-skill design system. See `REPORT.md` for the build report and `COPY.md` for the copy deck.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
